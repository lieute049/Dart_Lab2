# ToDo список на Dart

Консольное приложение для управления списком задач. Демонстрирует классы, конструкторы, методы, геттеры и статические поля в Dart.

## Как запустить

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/lieute049/Dart_Lab2.git
   ```
2. Перейти в папку:
   ```bash
   cd lab2_todo
   ```
3. Установить зависимости:
   ```bash
   dart pub get
   ```
4. Запустить:
   ```bash
   dart run
   ```

## Что изучили

- класс и объект: поля, конструктор, методы
- именованные параметры конструктора (`{required this.title}`)
- переопределение `toString()` через `@override`
- геттер `status` — вычисляемое свойство
- `static int _counter` — общее поле для всех объектов
- подключение внешних пакетов через `dart pub add`

## Ответы на вопросы

1. **Поле класса и переменная в функции.** Поле принадлежит объекту и живёт, пока жив объект. Переменная в функции существует только во время её выполнения.

2. **Конструктор.** Специальный метод, который вызывается при создании объекта и инициализирует его поля.

3. **`@override` перед `toString()`.** Аннотация говорит компилятору, что метод переопределяет родительский. Если убрать — код будет работать, но компилятор не проверит правильность имени, и опечатка приведёт к новому методу вместо переопределения.

4. **`static int _counter`.** Статическое поле принадлежит классу, а не объекту. В программе существует **одна копия**, общая для всех объектов.

5. **`_counter`.** Нижнее подчёркивание делает поле приватным для файла — снаружи файла обратиться к нему нельзя.
